Settings

Google Gemini — recommended, free

  1. Open aistudio.google.com/apikey and sign in with your Google account. No credit card needed.
  2. Click Create API key. If it asks for a project, pick Create API key in new project.
  3. Copy the key. It starts with AIza and is about 39 characters.
  4. Here: Brain mode = Google Gemini, Model = gemini-2.5-flash (or leave it blank, the app discovers a working model), paste the key, Save.

Check that the Key Type column says “auth”. Google retired the old Standard key type during 2026, so an older key gets rejected. If yours says Standard, delete it and create a new one — new keys are auth keys automatically.

Groq — alternative, free

  1. Open console.groq.com and sign up.
  2. Open API Keys in the sidebar → Create API Key → copy it.
  3. Here: Brain mode = Groq, Model = llama-3.3-70b-versatile, paste the key, Save.

Testing it

  1. Save, then send any message. If the key works the status bar changes to Online mode.
  2. If it fails, the exact error from Google or Groq is printed in the chat, so nothing is hidden.

Safety. The key is stored only in this browser's localStorage and is sent only to that provider. Never commit a key to GitHub, and if you host this project on Netlify or GitHub Pages, do not paste the key into the code — leave it as a browser-side key.
